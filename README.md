# ALICE // MIRRORFALL (Unity)

不思議の国のアリスをモチーフにした、Unity 2D縦スクロール弾幕シューティングです。外部アセットに依存せず、すべての演出・UI・サウンドをランタイム生成します。

## 動作環境

- Unity 2022.3.52f1
- 2D Core / Unity UI (UGUI)

## 起動

1. Unity Hubでこのリポジトリのルートをプロジェクトとして開きます。
2. `Assets/Scenes/Main.unity` を開いて Play を押します。

## 操作

- 矢印キー: 移動
- Z: ショット
- Shift: 低速移動（当たり判定表示）
- X: ボム
- P / Escape: ポーズ

キー設定画面から移動、ショット、低速、ボム、ポーズを変更できます。WASDとSpaceは初期割り当てではありません。ゲームパッドはD-Pad、Button 0のショット、Button 1の低速移動に対応しますが、ボムとポーズは割り当てられていません。画面上のタッチ操作にも対応しています。設定、ハイスコア、実績はPlayerPrefsに保存されます。

## 実装済み機能

- 2D縦スクロール、低速移動、当たり判定表示、ショット、ボム、残機、パワーアップ
- 時計ウサギ・トランプ兵・時計型の通常敵、3ステージ、各3スペル構成のボス戦
- 複数の弾幕パターン、グレイズ、チェイン倍率、アイテム回収とボム弾消し
- 難易度・主人公/ショットタイプ・開始ステージ選択、練習、コンティニュー、ポーズ、リトライ、ゲームオーバー、クリア結果
- ローカルランキング、詳細戦績、実績、ゴーストリプレイ、音量、演出軽減、文字サイズ、高コントラスト、オートショット
- キーリマップ、ゲームパッド基礎入力、タッチ操作、セーフエリア、全画面、アセット不要の手続き描画と手続きサウンド
- セーブデータのバックアップと復旧
